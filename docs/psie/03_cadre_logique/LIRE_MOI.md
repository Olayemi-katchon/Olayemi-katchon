# 📁 Dossier 3 — Cadre Logique du PSIE

## Déposez ici le cadre logique (ou matrice de cadre logique) du PSIE

### Fichiers attendus dans ce dossier

| Fichier attendu | Format | Description |
|---|---|---|
| Cadre logique officiel | `.pdf`, `.docx` ou `.xlsx` | Matrice intrants → activités → extrants → résultats → impact |
| Théorie du changement | `.pdf` ou `.docx` | Si disponible sous forme narrative ou schématique |
| Cadre de mesure de la performance | `.xlsx` ou `.pdf` | Indicateurs SMART avec cibles, valeurs de référence, sources |

### Ce qui sera analysé pour l'évaluation

Le cadre logique permettra de :

#### Pour la Cohérence interne (Section 5.2.1)
- Vérifier la solidité de la chaîne de résultats
- Identifier les hypothèses sous-jacentes et leur réalisme
- Évaluer si les ressources sont proportionnelles aux ambitions

#### Pour l'Efficacité (Section 6.2)
- Comparer les cibles prévues aux réalisations effectives
- Identifier les indicateurs de suivi disponibles
- Évaluer la qualité du cadre de mesure de performance

#### Pour la Pertinence (Section 4.2.3)
- Vérifier si la conception répond bien aux problèmes identifiés
- Évaluer si la théorie du changement est plausible dans le contexte béninois
