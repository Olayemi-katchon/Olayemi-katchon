## 📤 Comment partager vos documents sources

Ce guide vous explique comment déposer vos documents, **sans avoir besoin de connaître GitHub**.

---

## ⚠️ Important — Le copier-coller ne fonctionne pas pour les grands documents

> Le copier-coller dans la conversation ne fonctionne que pour de **très courts extraits** (moins de 2-3 pages).
> Pour un document de **59 pages ou plus**, il faut utiliser l'une des deux méthodes ci-dessous.

---

## 🥇 Méthode recommandée — Déposer le fichier directement dans GitHub

C'est la méthode la plus fiable pour des documents de grande taille (PDF, Word, Excel jusqu'à 25 MB).

### Étape 1 — Se connecter à GitHub

Allez sur [https://github.com](https://github.com) et connectez-vous avec votre compte.

### Étape 2 — Ouvrir la page de dépôt du projet

Allez sur : **https://github.com/Olayemi-katchon/Olayemi-katchon**

Ensuite, assurez-vous d'être sur la bonne branche de travail :
- En haut à gauche de la page, vous voyez un bouton avec le nom de la branche (ex. `main`)
- Cliquez dessus et sélectionnez la branche active de l'évaluation (votre collaborateur vous indiquera son nom exact si nécessaire)

### Étape 3 — Naviguer vers le bon dossier

Cliquez sur le dossier `docs`, puis `psie`, puis choisissez le sous-dossier correspondant à votre document :

| Votre document | Dossier où déposer |
|---|---|
| 📄 **Document de projet PSIE** (59 pages) | `docs/psie/01_document_projet/` |
| 📊 **Rapport de mise en œuvre** | `docs/psie/02_rapport_mise_en_oeuvre/` |
| 🗂️ **Cadre logique** | `docs/psie/03_cadre_logique/` |
| 📈 Données statistiques INSAE, ANPE | `docs/psie/04_donnees_statistiques/` |
| 📋 PAG, Politique Nationale de l'Emploi, etc. | `docs/psie/05_politiques_nationales/` |

### Étape 4 — Cliquer sur "Add file" → "Upload files"

Une fois dans le bon sous-dossier, regardez en haut à droite de la liste de fichiers :

```
┌──────────────────────────────────────────────────────┐
│  Olayemi-katchon / Olayemi-katchon                   │
│  docs / psie / 01_document_projet /                  │
│                                                      │
│  [Go to file]    [ Add file ▼ ]    [ <> Code ▼ ]    │
│                      │                               │
│                      ├── Create new file             │
│                      └── Upload files   ◄── ICI     │
└──────────────────────────────────────────────────────┘
```

Cliquez sur **"Upload files"**.

### Étape 5 — Déposer votre fichier

Vous arriverez sur une page avec une grande zone grise. Deux options :

- **Option A** : Faites glisser votre fichier depuis votre bureau ou votre dossier Windows/Mac directement dans la zone grise
- **Option B** : Cliquez sur le lien **"choose your files"** et naviguez vers votre fichier

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   Drag files here to add them to your repository     │
│                                                      │
│         or  choose your files   ◄── cliquez ici     │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### Étape 6 — Sauvegarder ("Commit changes")

Après avoir sélectionné votre fichier, faites défiler la page vers le bas.
Vous verrez un encadré vert intitulé **"Commit changes"**.

1. Dans le champ **"Add an optional extended description"**, vous pouvez écrire par exemple : `Document projet PSIE - 59 pages`
2. Laissez la sélection sur **"Commit directly to the [nom de la branche active]"**
3. Cliquez sur le bouton vert **"Commit changes"**

```
┌──────────────────────────────────────────────────────┐
│  Commit changes                                      │
│                                                      │
│  [Add files via upload                             ] │
│  [Document projet PSIE - 59 pages                  ] │
│                                                      │
│  ● Commit directly to [branche active]              │
│                                                      │
│  [ Commit changes ]  ◄── cliquez ici               │
└──────────────────────────────────────────────────────┘
```

> ✅ **Votre fichier est maintenant déposé !** Il sera lu et analysé pour compléter le rapport d'évaluation.

## 🥈 Alternative — Partager un lien Google Drive ou OneDrive

Si vous ne pouvez pas accéder à GitHub depuis votre ordinateur, ou si le fichier est trop volumineux (+25 MB) :

### Étape 1 — Uploader sur Google Drive
1. Allez sur [drive.google.com](https://drive.google.com)
2. Cliquez sur **"+ Nouveau"** → **"Importer un fichier"**
3. Sélectionnez votre document PSIE

### Étape 2 — Générer un lien de partage
1. Faites un **clic droit** sur le fichier uploadé
2. Cliquez sur **"Partager"**
3. Dans "Accès général", choisissez **"Toute personne disposant du lien"**
4. Cliquez sur **"Copier le lien"**

### Étape 3 — Envoyer le lien dans la conversation

Postez un commentaire sur cette page avec vos liens :

```
Voici mes documents PSIE :
- Document de projet (59 pages) : https://drive.google.com/file/d/XXXXXXX/view
- Rapport de mise en œuvre      : https://drive.google.com/file/d/XXXXXXX/view
- Cadre logique                 : https://drive.google.com/file/d/XXXXXXX/view
```

## 💡 Vocabulaire GitHub simplifié

| Terme GitHub | Signification simple |
|---|---|
| **Repository (dépôt)** | Dossier de projet en ligne, comme un classeur partagé sur internet |
| **Branch (branche)** | Version de travail du dossier (la photocopie sur laquelle on travaille) |
| **PR (Pull Request)** | Page de discussion et de travail collaboratif pour ce projet d'évaluation |
| **Commit** | Bouton "Enregistrer" dans GitHub |
| **Upload** | Déposer un fichier depuis votre ordinateur vers GitHub |

## ❓ Questions fréquentes

**Q : Mon document fait 59 pages — quelle méthode choisir ?**
> Utilisez l'**upload direct GitHub** (méthode recommandée ci-dessus) si le fichier fait moins de 25 MB.
> Sinon, partagez un **lien Google Drive**.

**Q : Quels formats de fichiers sont acceptés sur GitHub ?**
> PDF (.pdf), Word (.docx, .doc), Excel (.xlsx, .xls), images (.png, .jpg). Taille maximum : **25 MB** par fichier.

**Q : Mon fichier est confidentiel — que faire ?**
> Ce dépôt est public (visible par tous). Pour les documents confidentiels, partagez un **lien Google Drive en accès restreint** (seulement les personnes avec le lien).

**Q : Que faire si le fichier dépasse 25 MB ?**
> Compressez le PDF sur [ilovepdf.com/compress_pdf](https://ilovepdf.com/compress_pdf) — un PDF de 59 pages passe généralement en dessous de 10 MB après compression.
