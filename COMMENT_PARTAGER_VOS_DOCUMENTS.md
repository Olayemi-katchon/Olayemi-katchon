# 📤 Comment partager vos documents pour l'évaluation du PSIE

Ce guide vous explique comment déposer vos documents, **sans avoir besoin de connaître GitHub**.

---

## 💡 Vocabulaire GitHub simplifié (pour comprendre ce que vous voyez à l'écran)

> GitHub est un site web qui permet de stocker, partager et collaborer sur des documents et du code. Voici les termes que vous rencontrerez :

| Terme GitHub | Signification simple |
|---|---|
| **Repository (dépôt)** | Un dossier de projet en ligne, comme un classeur partagé sur internet |
| **Branch (branche)** | Une version de travail du dossier. Imaginez que vous avez le classeur original et une photocopie sur laquelle vous travaillez sans abîmer l'original. |
| **PR (Pull Request)** | Une **demande de fusion** : quand votre travail sur la photocopie est prêt, vous demandez à l'incorporer dans le classeur original. C'est simplement la page de discussion où toutes les modifications en cours sont visibles. **Vous n'avez pas besoin de comprendre ça pour partager vos documents.** |
| **Commit** | L'action de **sauvegarder** une modification dans GitHub (comme "Enregistrer" dans Word) |
| **Upload** | Déposer un fichier depuis votre ordinateur vers GitHub |

---

## 🎯 La méthode la plus simple pour vous : Copier-coller le texte

**Si vos documents sont en Word (.docx) ou en texte, faites ceci :**

1. Ouvrez le document dans Word
2. Appuyez sur **Ctrl+A** (tout sélectionner) puis **Ctrl+C** (copier)
3. Répondez à cette conversation GitHub en collant le texte (**Ctrl+V**)

C'est tout ! Pas besoin de maîtriser GitHub. Le texte sera analysé directement.

### Exemple de message à envoyer :
```
Voici le contenu du document de projet PSIE :

[Collez ici le texte du document]
```

---

## 📎 Méthode 2 — Partager un lien Google Drive ou OneDrive

Si vos documents sont sur votre ordinateur ou déjà en ligne :

1. Uploadez le fichier sur **Google Drive** (drive.google.com) ou **OneDrive**
2. Faites un clic droit sur le fichier → **"Partager"** → choisir **"Toute personne avec le lien"**
3. Copiez le lien et envoyez-le dans un message de cette conversation

### Exemple de message :
```
Voici mes documents :
- Document de projet PSIE : https://drive.google.com/file/d/...
- Rapport de mise en œuvre : https://drive.google.com/file/d/...
- Cadre logique : https://drive.google.com/file/d/...
```

## ❓ Questions fréquentes

**Q : Quels formats de fichiers sont acceptés ?**
> PDF (.pdf), Word (.docx, .doc), Excel (.xlsx, .xls), images (.png, .jpg). La taille maximale par fichier sur GitHub est de **25 MB**.

**Q : Et si mon fichier est confidentiel / ne doit pas être public ?**
> Ce dépôt GitHub est visible par tous sur internet. Si vos documents sont confidentiels, utilisez la **Méthode 1** (copier-coller dans la conversation, visible seulement des personnes ayant accès) ou la **Méthode 2** avec un lien Google Drive en accès restreint.

**Q : Que faire si le fichier dépasse 25 MB ?**
> Compressez le PDF via [ilovepdf.com](https://ilovepdf.com/compress_pdf), ou extrayez les pages les plus importantes.

**Q : C'est quoi une "PR" ou "Pull Request" exactement ?**
> C'est simplement la **page de travail collaborative** où toutes les modifications en cours de l'évaluation PSIE sont rassemblées. Vous pouvez y lire les fichiers, envoyer des messages (commentaires), et voir l'avancement du rapport. Vous n'avez pas besoin de créer ou gérer des PR vous-même.
